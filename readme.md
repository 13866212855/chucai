# 企微办公 — 外出事务与出差审批管理系统

企微办公外出事务管理系统是一套面向企业员工与管理团队的高效、合规、规范化的出差与外出事务申报审批平台。系统支持完整的申请填报、预算核算、单据导出、审批追踪及数据统计分析。

---

## 核心功能介绍

1. **外出事务填报与多行程规划**
   - 支持设置出差、学习培训、公干及其他多样化外出事务类型。
   - 支持规划多途径城市路线（如“北京 ➔ 深圳”），精准计算出行天数。
   - 精细化差旅预算明细拆解（交通费、住宿费、餐饮费、其他杂费）。
   - 随附支持证明文件、票据附件与实地考察水印现场照片。

2. **智能本地草稿箱与快速录入**
   - 填报时内容自动实时防丢失暂存。
   - 支持一键恢复上一次未保存的草稿，或一键重置清空。

3. **标准公文审批单与高清导出**
   - 自动生成合规的企业外出事务凭证单据，附带官方红头字样、标准公文编号、审批流水轨迹与专用审批公章。
   - 支持一键导出高清晰度 PDF 凭据单或直接打印，方便报销与归档。

4. **月度出行数据统计与可视化看板**
   - 统计当月外出次数、累计出行天数与总预算消耗。
   - 城市出行分布排行、活动类型分布及月度趋势全景展现。

5. **数据持久化与安全保护**
   - 基于 SQLite 数据库持久化存储业务记录与数据。
   - 配备应用内二次删除确认模态弹窗，保障数据操作安全。

6. **大模型与双环境部署支持 (myusellm)**
   - 已内置 APIHub 大模型连接配置与通用请求客户端。
   - 内置生产级 Docker 镜像构建配置（`Dockerfile`、`Dockerbak.txt`、`.dockerignore`）。
   - 提供 Windows 本地一键部署批处理脚本（`redeploy.bat`）及远程 Linux 服务器自动化部署脚本（`upload2remote.bat`）。

## 本地开发与运行

### 环境要求
- Node.js 20+
- npm / pnpm / yarn

### 运行步骤
1. 安装依赖：
   ```bash
   npm install
   ```
2. 启动本地开发服务：
   ```bash
   npm run dev
   ```
3. 在浏览器中打开：[http://localhost:3000](http://localhost:3000)

---

## Docker 容器化部署

### 1. 本地一键部署（Windows）
在项目根目录直接双击执行 `redeploy.bat`，脚本将自动完成：
- 构建 Docker 镜像：`chucai:latest`
- 挂载本地数据目录 `D:\docker\chucai\data` 映射至容器 `/app/data`
- 映射本地端口 `7860:3000`
- 部署成功后可通过 [http://localhost:7860](http://localhost:7860) 访问

### 2. 远程服务器一键部署（Linux）
在项目根目录直接双击执行 `upload2remote.bat`，脚本将自动完成：
- 本地构建 `chucai` 镜像并打包为 tar 包
- 通过 scp 上传至远程服务器 `172.29.173.42`（用户 `gpzx`）的 `/bak/tar`
- 通过 ssh 加载镜像、配置挂载目录权限
- 停止旧容器并以端口 `7860`（宿主机对外端口）启动全新容器
- 部署完成后可通过 `http://172.29.173.42:7860` 访问系统
